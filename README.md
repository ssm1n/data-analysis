# 난임 환자 데이터 기반 임신 성공 여부 예측

> LG AIMERS 6기 데이터 분석 해커톤  

---

## 프로젝트 개요

난임 환자의 시술 데이터를 분석하고, 데이터 전처리 및 feature engineering을 통해 임신 성공 여부 예측 AI 모델을 개발한 프로젝트입니다.

## 수행 내용

- EDA 기반 데이터 특성 및 상관관계 분석
- 결측치 및 이상치 처리
- Label Encoding / One-Hot Encoding 적용
- 데이터 스케일링
- feature 처리

## 사용 기술

- Python
- Pandas
- Plotly
